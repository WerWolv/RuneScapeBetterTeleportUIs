# RuneScape3 Better Teleport UIs Plugin

This plugin replaces many of the existing Modal Dialog-based Teleport UIs with pretty maps where you can visually see where you're teleporting to.

![Screenshot](dist/screenshots/screenshot.png)

- [mod.io Page](https://mod.io/g/runescape/m/better-teleport-uis)

## Currently supported UIs

- Wilderness Obelisks, Portable Obelisk and PoH Obelisk
- Drakan's medallion
- Ring of Duelling
- Games necklace
- Crystal teleport seed and PoH Crystal Seed
- Passing bracelet
- Underworld Grimoire 2, 3 and 4
